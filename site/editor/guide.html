Make a little model.

PC 工作台：Shift 多选，B 框选，F 聚焦，G / R / S 移动、旋转、缩放，X 切换穿透。数值在回车或移开焦点时保存，Esc 取消输入；Ctrl / Cmd + Z 撤销，Shift + Ctrl / Cmd + Z 重做。吸附步长和角度可设置，长度输入支持 m/cm/mm，网格显示实际间距。物体模式才能删除整个部件。

Desktop workshop: numeric edits commit on Enter or blur; Escape cancels. Front, side and top views are orthographic. Focus frames the selection. Use Material, Clay or Silhouette shading to inspect shape. The work surface supports desktop widths of 1024px and above.

形状保留分段和轮廓参数。轮廓可以回折制作内壁；拖点改形，双击线段加点，Delete 删除聚焦的点。转为网格后可以多选顶点或面进行变换、挤出、内插。简单倒角用于闭合凸体；边模式支持凹槽等闭合网格的局部倒角，以及四边面环切。平面切线可按轴和位置分割面。截面编辑提供轴约束、坐标、独立撤销和实时 3D 预览。联动副本和对称部件从源部件继承几何，解除联动后可独立编辑。

Drafts use a single-writer browser lock. A second window is read-only: close the original and Reconnect, or open an Independent copy. Download project JSON for backups. A GLB is a runtime delivery file; it does not include editor helpers or procedural relationships.

树中的圆点控制隐藏，菱形控制锁定；隔离选区方便编辑内部结构。它们是当前窗口的观察状态，不会删除模型或影响 GLB 导出。框选尊重穿透开关。金色为主选区，蓝色为其他选区。多选复制和赋材质作用于整个选区，赋材质会显示联动影响数量。

Wait for window.funEditor: renderer initialization is asynchronous, but renderViews still returns images synchronously.

Wait for window.funEditor. The API is local to this browser page; it neither uploads nor publishes. Project JSON remains fun.dev/model v1, with optional generator and link metadata. API v3 adds guarded component references, recipes, previews and persistent checkpoints. It defaults extrusion to world meters and reparenting to preserving world appearance.

Method Result / behavior
capabilities() JSON Schema for all commands and geometric queries, limits and supported features. Pass {detail:"summary"} for the small command index, or {command:"recipeStep"} for one complete schema. MCP capabilities defaults to the summary; execution always uses the complete schema for validation.
query({id,kind,...}) Faces by normal/largest area; components on a plane; edges by length/crease; adjacentTo face IDs; quad edge rings via loopFrom ref. Returns items with current {node,kind,id,topology} refs, total, truncation and nextOffset. Continue with offset and the same topology token and ifRevision from the first page. A changed revision invalidates pagination.
preview(commands,{ifRevision,views?,size?,detail?}) Evaluate without changing project/revision/history; returns compact proposed nodes/bounds, materials, name, per-command results, validation and optional images. detail:"full" additionally returns the complete proposed project mesh.
checkpoint({name},{ifRevision}) / checkpoints() Up to five persistent named snapshots. restoreCheckpoint(id,{ifRevision}) restores as one undoable change; removeCheckpoint removes one. Browser storage errors are explicit.
activity() / getSession() Recent changes/errors; complete local session with project, revision, checkpoints and activity. Editable project JSON itself excludes session history.
exportReport({ids?,mergeStatic?,origin?}) Editable/render/unique-buffer vertices, shared geometry, triangles, material groups and bounds. Optional static merging accepts leaf meshes and removes their separate runtime names.
inspect({id?,detail?}) Revision, draft ID, writable state, meter units. Without ID: selection, stats, camera, node world bounds, materials with user IDs, and session viewState (hidden, locked, isolated). With ID: compact node and recipe metadata, counts, topology token, world matrix and bounds. Use detail:"full" for the complete mesh, world face centers/normals and edge references. getProject() returns the complete editable project.
getRecipe({id,index?,ifRevision?}) Read the retained recipe (including the base mesh for scripted sources). With index, returns only the saved step, evaluated arguments, parameters, basis and revision, without mesh arrays.
recipeStage({id,index,query?,views?,size?,ifRevision?}) Read input geometry before a recipe step; index equal to step count reads append input. Returns compact input metadata, paginated components with guarded refs, saved/evaluated step and optional images. Query coordinates are before bakes (local only); images show placed geometry and highlight the query page. No document or view changes. Use these refs when inserting/updating this step, instead of refs from the final mesh. Fixed refs expire when input geometry changes.
getProject() An independent editable JSON copy.
loadProject(project, {ifRevision}) Validate, replace, frame and autosave; undoable.
importGLB({data,mode?,parent?,name?}, {ifRevision}) Open a GLB given as base64 data (the local adapter also accepts path). A project file (.funmodel.glb) restores its editable project exactly; any other GLB becomes editable parts: node hierarchy, glTF names as IDs, flat PBR materials, polygons merged from coplanar triangles, repeated meshes as linked copies. mode "replace" (default) or "add" (parts under parent; clashing IDs get suffixes). One undoable change. Returns revision, nodes (added IDs), container and warnings: skins, morph targets, animations, textures, cameras and lights are reported, not imported. Compressed files are refused.
librarySearch({query?,type?,kit?,tags?,limit?,offset?,locale?}) Search the public CC0 model library: listed models matching every word of query (id and name first, then tags, then descriptions) with size in metres, newest version, thumbnail and page addresses, and the agreement of each kit in the results.
libraryModel({id}) A library model in both languages with every version: stats, editable (has a workshop project), file addresses and the derived .fun3d.
openLibraryModel({id,version?,mode?,parent?,name?}, {ifRevision}) Open a library model to edit or derive from: its workshop project when it has one, else model.glb as parts; mode "add" adds its parts to assemble a scene. One undoable change. The project records it in sources (kind, id, version, file, sha256). See docs/library-api.md in the repository.
exportProject() The project file: a GLB of the model (all parts, world origin) whose FUNDEV_workshop extension holds the editable project. Returns revision, filename (name.funmodel.glb), mimeType, bytes and base64 data; the adapter writes it to --artifacts.
apply(commands, {ifRevision}) 1–256 commands in one atomic history entry. Returns revision, statistics, changed/removed node IDs, materials and per-command geometry results. operationId deduplicates the last 32 acknowledged requests; label appears in Activity. Errors include commandIndex (zero-based), operation, node, components, path and geometry issues. Linked geometry is synchronized between commands. Invalid commands leave state untouched. Pending valid human input commits first, so a stale agent revision is rejected.
undo() / redo() Revision is monotonic, including history changes and reloads. History is in memory, bounded to 30 entries / about 8 MB per direction.
select(idOrIds, {mode, faces, vertices, edges}) Modes: object, face, vertex, edge. Edge keys are sorted vertex indices, e.g. "2:3". Inspect again after topology changes. Components belong to the last selected node. Singular face / vertex / edge fields also work.
view(name, {focus, projection, preserve}) / focus() front, back, left, right, top default to orthographic; perspective defaults to perspective. focus:true frames the selection. focus() keeps the camera direction. preserve:true changes direction/projection without reframing the current working target.
renderViews(names, {size:512, focus, projection}) 1–6 PNG observations, each with revision, draftId, camera (projection, world/projection matrices, target, frustum), shading, view, width, height, mimeType, dataUrl. Size: 64–2048. Includes current view. Options: ids, visibility:"all", shading:"material"|"clay"|"silhouette"|"ids", helpers, overlays:{wire,selection}, camera:{position,target,up?,projection?,near?,far?,fov?,height?,zoom?}. Observation metadata records visible IDs, selection, view state, helpers/overlays and object-color lookup. All temporary view changes are restored.
validate(budget) Revision, geometry errors/warnings, statistics and explicit check coverage. Topology edits reject surface intersections/collapse; inward closed shells are warnings. Inter-object collisions and minimum wall thickness are not certified. Budget fields: triangles, vertices, drawCalls. drawCalls counts mesh/material groups, not measured renderer passes.
exportGLB({encoding,ids?,origin?,rootName?}) buffer (default) or base64. Base64 result: revision, filename, mimeType, data, report (including bytes). Indexed geometry retains flat normals and identical geometry shares buffers. Optional ids selects subtrees; mergeStatic explicitly combines static leaf meshes by parent and material into static__<material> (under the root) or <parent>__<material> nodes; rootName names the exported root (e.g. crate_01_ROOT); a single top-level part becomes that root itself. Takes a snapshot before asynchronous export. origin is "world" (default), "asset-root" (one ids root required) or "ground-center". The chosen project-space anchor moves to zero in the exported scene; orientation, scale and hinge relationships are preserved. Reports include that anchor and exported bounds.

Commands · 编辑命令

World units are meters; Y is up, front is +Z, rotations are XYZ Euler degrees. Node transforms are local to their parent. Component mutations require query/inspect refs, or a topology token with raw IDs. Geometry edits invalidate earlier refs. A geometry edit bakes/removes its generator or recipe; the UI exposes an explicit Convert to mesh action. Linked targets must be edited through their source or unlinked first.

op Fields
create id, name?, kind, parent?, position?, rotation?, scale?, material?, options?. box, sphere, cylinder, cone, extrude, lathe, revolve, sweep, group, mesh. Custom mesh uses the top-level mesh field.
recipe / recipeParameters / recipeStep recipe: id, definition:{parameters,generator,steps,basis?}; recipeParameters: id, values. Local-meter steps rebuild atomically; {$param:"width",factor?,offset?} references a named value. No script strings. Inspector includes a hollow-box preset. recipeStep: id, action (append/update/patch/remove/move), index?, to?, step?, patch?. Append inserts at index or the end. On a primitive, the first append keeps its shape and promotes it to a recipe, retaining colors, baked transforms, asset dimensions and linked copies. getRecipe exposes that implicit recipe; recipeStage also accepts scripted mesh sources. For kind:"mesh", a recipe retains generator:{kind:"mesh",mesh:{vertices,faces}} as its base, including face colors. All subsequent steps rebuild from that base. recipeStage index 0 inspects its unbaked shape. The inspector also offers Keep shape and start modeling steps. Update replaces a step. Patch replaces supplied fields only; null removes an optional field. Nested selectors are replaced as a whole. Read getRecipe first. Steps support enabled and label. Failed steps report recipeStepIndex, recipeOperation, evaluated recipeArguments, recipeParameters and a node/step path, including over MCP. Whole-mesh transforms modify geometry before the next step while retaining object TRS. Scope previews show matched components on the input geometry before a step. Fixed selections require rebinding after geometry changes; normal/boundary selectors follow dimensions. Direct component edits detach recipes.
parameters / convert id, options updates retained generator parameters. On a recipe it edits literal base shape options and rebuilds the steps. Options driven by expressions require recipeParameters; assembly dimensions remain controlled by their asset. convert takes id and freezes the current mesh.
set id, name?, parent?, position?, rotation?, scale?, keepWorld?. Reparenting preserves world appearance by default, including affine shear via geometry baking. keepWorld:false explicitly keeps local transforms. Additional supplied TRS values override the preserved transform.
transform ids for objects, or id, vertices:[indices] / id, faces:[ids] / id, edges:[keys] for components; translation?, rotation?, scale?, pivot?, space?. Default space: world; default pivot: selection bounds center. Local space uses the last (active) node's frame, matching the viewport gizmo. A finite affine column-major matrix may supply an exact world delta. Selected parent/child objects are transformed only once. A selected mirrored pair supports transforms that preserve its plane; group the pair for arbitrary overall movement.
dimensions / applyScale id, size:[x,y,z] sets world bounds dimensions about their center. applyScale takes id, resets scale to 1 and preserves geometry, children and generator shape.
ground / align ids. ground places each root on Y=0. align adds axis, mode:"min"|"center"|"max", reference?; default reference is the last selected ID.
array id, count (2–256), offset?:[x,y,z], rotation?:[x,y,z], pivot?, linked?, merge?, newIds?. Each copy steps by rotation about pivot, then offset, in the parent's coordinates (pivot defaults to the part's origin; give one for radial arrays). Copies are linked parts named <id>_2… (descendants <child>_2…) unless newIds lists the roots; linked:false copies independently. merge:true appends the copies to this part's own mesh in local coordinates; that form is also a recipe step, so count can be a parameter. Overlapping merged copies stay separate shells and only warn (shell-overlap).
vertices id, changes:[{index,position:[x,y,z]}]. Absolute local coordinates.
extrude id, faces:[ids], distance, space?; singular face also works. Shared edges of a coplanar region create no internal side walls. Default distance: world meters; space:"local" opts into local distance. Cap IDs survive.
inset / bevel id, distance, space?. inset also takes faces or face, insets convex faces individually. bevel without edges applies one segment to a closed convex solid. With edges:[keys], bevel trims selected edges of a closed consistently oriented mesh with planar, locally convex adjacent faces, including concave recessed solids. Too-wide or unsupported operations are rejected atomically.
cut / loopCut cut: id, axis, offset, space? splits polygons across a plane, preserving the surface. loopCut: id, edge, ratio:.5 follows a manifold quad strip; ratio must be .01–.99. Both freeze generator geometry.
group ids, newId, name? creates a container at selection bounds center and preserves world appearance. Internal mirrored pairs carry their plane with the container. Select both source and target when grouping a linked pair.
symmetry id, newId, axis:"x"|"y"|"z", offset:0, space:"world"|"parent", linked:true, name?, idMap?, replace?. Reflects the subtree across the specified center plane with corrected winding. Linked geometry, transforms and materials follow the source. linked:false creates an independent mirrored copy. Descendant IDs: idMap entries, else replace:["_l","_r"] (last occurrence), else newId-1, newId-2… The result lists idMap.
duplicate / unlink id,newId,name?,offset?,linked?,idMap?,replace?. Clone subtree, default parent-space offset [.2,0,0]. linked:true shares source geometry/materials but keeps independent placement. Descendant IDs follow idMap / replace as for symmetry, else newId-1, newId-2, etc. unlink takes id and releases subtree links.
mirror / pivot mirror: id,axis, flip mesh locally, leaving children unchanged. pivot: id,offset:[x,y,z], relocate local origin while preserving geometry and child world positions.
paint / material paint: id,material,faces?. material: id,name?,color?,roughness?,metalness?,emissive?,emissiveIntensity?,opacity?,transmission?,ior?,doubleSided?, update shared material or create with #rrggbb color. Glass: transmission (KHR_materials_transmission) with ior; emission: emissive colour and strength (KHR_materials_emissive_strength); opacity below 1 blends. null removes an optional property. UI Make unique clones and assigns a material in one transaction.
delete / renameProject delete takes id, removes subtree and linked mirrors; surviving geometry copies become independent. renameProject takes name.
rename id,newId. A node ID is its glTF name, so games find parts by it (wheel_front_l, door_hinge…). Parents, mirrors, linked copies, asset bindings and anchors follow.
boolean id, operation:"union"|"difference"|"intersection", with?:[ids], shape?:{kind,options,position?,rotation?,scale?,material?}, keep?. Closed solids only. with parts are placed in the world and used up unless keep; shape is an inline primitive in this part's local coordinates and is the form a recipe step takes, so a parametric hole follows its parameters. Cut faces keep the tool's material; faces split by a hole become a few simple polygons.
deleteComponents / dissolve deleteComponents: id, faces | edges | vertices | select, removes those faces (or every face using the edges/vertices) and leaves an open boundary. dissolve: id, edges | vertices | select, angle? joins coplanar faces across edges (angle in degrees, default 0.1) or removes vertices; with no components it cleans the whole mesh (coplanar faces of one material merge, collinear corners drop out) — use it after imports and booleans. Results stay simple polygons of at most 64 corners.
weld / fill weld: id, distance?, vertices?, space? merges points within distance (default 0.00001 world meters) at their centre; coincident faces collapse, pinched faces are refused. fill: id, edges?, material? closes every open boundary, or the loops containing the edges; large holes split into several faces.
bridge / connect bridge: id, faces:[a,b] removes two faces with the same corner count and joins their loops with quads (a tunnel between two inset faces), or edges on two open boundary loops. connect: id, vertices:[a,b] splits one face along a new edge between two of its corners.
solidify id, thickness, offset?, space? thickens an open surface into a closed shell; offset -1 (default) grows against the normals, 1 along them, 0 both ways. On a closed mesh it adds an inward cavity shell. Thickness is world meters; corners keep an even wall.
separate / join separate: id, newId, faces | select | loose:true moves faces (or every loose part after the first: newId, newId-2, …) into new parts with the same parent and transform. join: id, with:[ids] moves other parts' geometry into this part's coordinates and consumes them; their children and mirrors stay. Overlapping parts stay separate shells (a shell-overlap warning); boolean union makes one clean solid.

Primitive options: box {size:[1,1,1],bevel:0,bevelSegments:1} (more than one bevel segment rounds every edge and corner; the six flat sides keep IDs f0–f5); sphere {radius:.5,segments:8,rings:6}; cylinder/cone {radius:.5,height:1,segments:8}; outline extrusion {points:[[x,y],…],depth:.5}; lathe {profile:[[radius,height],…],segments:8}. Ordered lathe profiles may return down an inner wall; use axis endpoints to close a hollow container. Extrusions also take holes:[[[x,y],…],…] (inside the outline, apart from each other) and round (corner radius for the outline and holes, roundSegments 3): concave corners fill in, convex corners cut off. Without holes and within 64 corners the faces keep the plain layout (caps f0/f1, then sides); otherwise caps split into a few simple polygons. revolve {profile:[[x,y],…],holes?,round?,segments:12,angle:360} turns a closed section (x = distance from the Y axis, ≥ 0) around +Y; segments count a full circle; below 360° it starts on +X, turns like a positive rotation about +Y and caps both ends (elbows, rings, arches). sweep {profile:[[x,y],…],path:[[x,y,z],…],round?,smooth?,pathSegments:6,closed?,caps:true,scale?} moves a closed section along a path with rotation-minimising frames: profile x runs sideways, y up (a level path keeps y on +Y; a vertical start uses −Z). Polyline corners are mitred to keep the thickness and may turn at most 150°; smooth runs a centripetal Catmull–Rom curve through the points; closed joins the ends without caps; scale is the end scale (number or [x, y]). Curved sweeps keep slightly non-planar quads, reported as warnings.

Project · 工程

{
  "format": "fun.dev/model", "version": 1, "name": "My model",
  "materials": [{ "id": "yellow", "name": "Yellow", "color": "#ffd43b", "roughness": 0.85 }],
  "nodes": [{
    "id": "body", "name": "Body", "parent": null,
    "position": [0,0,0], "rotation": [0,0,0], "scale": [1,1,1],
    "mesh": { "vertices": [[0,0,0],[1,0,0],[0,1,0]],
      "faces": [{ "id": "front", "vertices": [0,1,2], "material": "yellow" }] }
  }]
}

Limits: 512 nodes, 32 materials, 30,000 editable vertices, 50,000 triangles, 64 vertices per polygon, 8 MB project JSON. Nodes may additionally retain generator {kind,options,material,basis?}, symmetry {source,axis,offset,reference,basis?}, or instanceOf with optional instanceBasis. Link cycles are rejected. Errors throw; a non-writer throws code "readonly"; stale ifRevision throws with code: "conflict". Non-planar faces are triangulated and reported. Validation does not judge appearance or measure device frame rate.

Model pages offer Open in workshop: /editor/?open=<id>&version=vNNN opens that version in a new draft, from its source.funmodel.glb when it has one, otherwise from its model.glb.

Save editable JSON with the game's development files. Place the GLB in games/<id>/assets/, include it in game.json, and run npm run assets. The game loads it using createAssets(context).gltf("assets/model.glb"). Resolve parts using scene.getObjectByName("body").

Round shapes · 圆形和曲线

圆柱和圆锥可以设顶半径（圆台）、内半径（管、垫圈）、边缘圆角和旋转角度（半管）；球可以设纬度范围（穹顶、碗）和角度；新增圆环（弯头）和胶囊。“朝向”把圆形横放到 X 或 Z 轴。分段数留空就是自动：按大小定，约 2 毫米弦差。轮廓每行第三个数是该角的圆角半径；以 { 开头的一行是 JSON：{"arc": {"center": [x, y], "angle": 90}} 接着上一点画圆弧，{"arc": {"through": [x, y], "to": [x, y]}} 经过一点画到终点，单独一行 {"circle": 0.1} 让整个轮廓是圆。部件面板的“平滑着色”让圆的部分显得圆，折角以上的边保持硬边。

Cylinders and cones take a top radius (frustums), an inner radius (tubes), a rim radius and an angle; spheres a latitude range (domes, bowls); tori (elbows) and capsules are new; the axis lays round shapes along X or Z. An empty segments field means auto (about 2 mm from the true curve). In outlines a third number rounds that corner and JSON lines add arcs, curves or a whole circle. Smooth shading in the parts panel makes round parts look round while edges sharper than the crease stay hard. Agents: options.radiusTop, innerRadius, latitude, axis, segments: "auto", outline items and smooth (see the quick reference).

Blueprints · 蓝图

A blueprint is a parametric model family: funEditor.blueprints() lists them with their parameter schemas (id, version, title, params with value, min, max, unit, structural). Build one with apply([{op:"blueprint", id:"lamp-post", params:{height:6, arms:2}, root:"lamp_1"}]): it expands into the parts under root and an assembly whose live parameters keep driving them, so {op:"assemblyParameters", root:"lamp_1", values:{height:4.5}} re-derives the model; structural parameters (counts, styles) are fixed when built — apply the blueprint again to change them. The assembly records blueprint:{id, version, params}. Every command of the expansion reports the blueprint's index. Blueprints are modules in /editor/blueprints.js: a title, a parameter schema, materials and a build(values, {root, id}) that returns parts and bindings, using the same library conventions as hand-built models. 蓝图是参数化的模型族：blueprints() 列出参数；blueprint 命令按参数生成零件和驱动它们的装配体，之后用 assemblyParameters 改实时参数即可衍生新模型；结构参数（数量、样式）要重新生成。 npm run derive 在命令行里完成同样的事并写出可上传到库的文件夹。

Durability and asset parameters

Inspect persistence and await funEditor.flush() after synchronous mutations. MCP waits for saving before replying. IndexedDB stores the full draft; a compact local journal protects interrupted saves. Pending recipe or asset inputs block unrelated edits until Rebuild or Cancel.

funEditor.presets() returns the hollow-box recipe and toolbox assembly commands. On an empty default-palette project, apply presets().toolbox, then use {op:"assemblyParameters",root:"toolbox",values:{width:.92,height:.5}}. Asset parameters drive body, lid, feet and hinge anchors together; derived values and dependency cycles are checked. Detach with {op:"assembly",root:"toolbox",definition:null}.

Expressions support {$param:"width"}, {$expr:"sub",args:[a,b]} (add/sub/mul/div) and assembly {$anchor:{node:"body",point:"max",axis:"y"}}. Anchors use the driven part's parent frame. See capabilities().commands.$defs for the complete schema.

Assets own their parameter scopes in assemblies. Independent, shared-parameter and static copies are explicit. Anchors use the driven parent's frame; rotating an asset preserves its internal layout. Imported recipes and assemblies are evaluated before export. Use {op:"detachBinding",id:"body"} to release one part. Material segmentation failures provide recovery commands; the inspector can rebind by local face direction and rebuild in one step.

Shared instances support per-parameter overrides: {op:"assemblyParameters",root:"second",override:true,values:{openAngle:-90}}. Reset with values:{},resetOverrides:["openAngle"]. {op:"detachBinding",id:"hinge",fields:["rotation"]} keeps the position attachment while releasing rotation.

Assets may nest. A child declares exposed:["width"]; the parent can bind its root using {id:"toolbox",assetValues:{width:{$param:"width"}}}. Child internals stay owned by the child, and dependency cycles reject atomically. Static export merges are partitioned by parent and material, preserving asset and hinge motion. Inspect mergeGroups for source IDs.

Material rules evaluate every matching face, independently of query pagination; replies include matched counts. Damaged saved data enters protected recovery. The editor displays the intact project or cached geometry and keeps originals read-only. Download original data or recover an independent copy from the banner. Valid recipes remain editable in the copy; failed dependencies become static geometry. getSession() (MCP fun_editor_getSession) includes original recovery sources for backup. Protected MCP session files remain unchanged, including on shutdown.

Local face colors on primitives start a zero-step recipe while keeping base-shape editing available. Face colors retain their recipe across dimension changes. Incompatible topology rejects the rebuild and requests a material remap. The shape dialog can preview a directional repair or cleared overrides; Apply commits the repair with the shape edit, and Cancel discards both. An open shape dialog reports pendingInput and blocks agent mutations.

Apply replies use compact geometry counts; request includeComponents:true for full refs. The last 32 operation IDs support retries. MCP also exposes undo, redo and presets.

Exports validate selected roots, remove unrelated nodes and attach diagnostics. Errors block export unless force:true is explicitly requested. Observation camera descriptions can be replayed directly through MCP.
