给 agent 用

工坊是一个 Node 程序，agent 用脚本或 MCP 调它造模型；只要 Node 22，不要浏览器和显卡。

一个脚本造一个模型

写 model.mjs，运行，看预览图，改，再运行。

npx -y fundev-workshop --run model.mjs
// model.mjs
export default async function (ws) {
  await ws.load({ name: "crate_01", materials: [
    { id: "mat_wood", color: "#c89969", roughness: 0.8 },
  ] });
  await ws.apply([
    { op: "create", id: "crate_01", kind: "group" },
    { op: "create", id: "body", kind: "box", parent: "crate_01", material: "mat_wood",
      position: [0, 0.25, 0], options: { size: [0.5, 0.5, 0.5], bevel: 0.01 } },
  ]);
  await ws.observe(["perspective"], { file: "preview.png" });
  await ws.exportGLB({ file: "model.glb", origin: "ground-center" });
}

MCP

加进 Claude Code、Codex、Cursor 等的 MCP 配置，agent 就有了 fun_editor_* 这一组工具。

{
  "mcpServers": {
    "fundev-workshop": {
      "command": "npx",
      "args": ["-y", "fundev-workshop", "--mcp", "--session", "model.json", "--artifacts", "out"]
    }
  }
}

模型库

先找现成的再改：搜索、打开、派生，都是 CC0。

const { models } = await ws.librarySearch({ query: "street lamp" });
await ws.openLibraryModel(models[0].id);      // edit or derive from it
await ws.openLibraryModel("city_taxi_01", { mode: "add" });   // assemble a scene
